# Phishing Email Detection & Awareness System

## Project Overview
This project focuses on detecting phishing emails and creating awareness about email-based cyber threats.

The system helps identify suspicious email characteristics and provides information to improve cybersecurity awareness.

## Project Objective
- Understand phishing email threats.
- Identify suspicious email patterns.
- Improve awareness of email security.
- Support safer email communication.

## Project Files
- `Phishing_Email_Detector.html` – HTML file for the phishing email detection system.
- `Phishing Email Detection Report.pdf` – Project report documenting the work.
- `evidence/` – Folder containing screenshots and supporting evidence.

## Technologies Used
- HTML
- Cybersecurity concepts
- Phishing detection techniques
